Tournoi

Clique sur un joueur pour le déclarer vainqueur : il passe automatiquement au tour suivant. Re-clique pour annuler. En double élimination, le perdant passe automatiquement dans le tableau des repêchages. En poules, clique le vainqueur de chaque match : les qualifiés rejoignent la phase finale dès que la poule est terminée (égalité : confrontation directe, sinon ordre du tirage).
